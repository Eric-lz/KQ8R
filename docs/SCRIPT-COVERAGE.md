- **Commands and Connor's states**: each was run once in an empty world, with a real line from the data. *built* = our build handles the word (it can still be partial or a stand-in); *stub* = accepted, does nothing yet; **missing** = "unknown command" in our log.

A command also used during play was probed as above.
- "loading hint?": the name looks like a loading or memory instruction with nothing to see; to be confirmed by session A.
