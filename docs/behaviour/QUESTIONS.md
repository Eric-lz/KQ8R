# Questions for the study session

The implementation session (B) adds questions here when a behaviour note is
unclear, incomplete or seems wrong. The study session (A) answers them in
the relevant note and marks them answered here.

| Q1 | none yet (models, `.kqs`) | How are model transforms applied? Each mesh node and sequence has a 3×3 matrix + translation. Data hint (`kq8 shape-verify`): parts of multi-part models meet more often this way (4,891 touching vertices vs 2,761 transposed; 245 models clearly better vs 7), but that is not proof. Please confirm (a) row or column vector, (b) node then sequence or the other order, (c) whether the flag bits (1 rotation, 2 translation, 4 scale) change how the matrix is used. | B, M1 step 1, 2026-10-11 | **answered** in `models-and-textures.md`: (a) row vector, confirmed; (b) frame transforms are NOT used when drawing parts, they move the whole object (from data, high confidence); (c) flags are hints only |

| Q6 | none yet (terrain, `kq/Terrain/TERRAIN.KQ`) | How big is the terrain? Daventry: `groundScale=12`, `heightBMPScale=255`; the height image `terrh.dib` is 129×129 grey values 0–254 (a corner grid for 128×128 squares). Other worlds use `groundScale` 11 or 12 and `heightBMPScale` 48, 138 or 255. Please give: the size of one square in game units, the height in game units of one grey step (and how `heightBMPScale` enters it), and whether heights between corners are interpolated (and how: two triangles per square? which diagonal?). Measured, not settled: Daventry objects lie within x 0–311,127, y 0–378,503, z −2–30,600, which would fit 4,096-unit squares (2¹²), but comparing object heights with the image gave no clear fit (best 23 of 247 objects on the surface, several scales tied). What is `floorBMPName` (`terrh2.dib`, nearly identical to `terrh.dib`) for? | B, M1 step 2, 2026-10-11 | **answered** in `terrain.md`: square = 2^groundScale (4,096 for 12, 2,048 for 11); height = value × heightBMPScale (measured in 3 worlds); two flat triangles per square, diagonal alternating like a chessboard |
